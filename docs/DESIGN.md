# Mothglass — Design Brief

## One-line

A quiet observation puzzle: place a dream-lamp so cast shadows cover remembered silhouettes — without letter grids or 3D rotation.

## Pillars

1. **Original mechanic** — shadow coverage + penalty zones (+ optional prop rotation).
2. **Art-game restraint** — minimal HUD, soft ink, no tutorial walls of text.
3. **Ship structure** — EN/VI loc, settings, chambers select, fade transitions, pause.

## Not this

| Title | Their hook | We avoid |
|---|---|---|
| HER TREES | Align → letter grid | No alphabet / grid entry |
| Monument Valley | Rotate impossible architecture | No 3D yaw puzzles |
| The Witness | Line panels | No line-drawing |

## Tone

Museum after closing. Warm parchment. One lamp. Shadows that almost tell the truth.

## Scope (v0.2)

- 5 chambers, escalating precision
- Boot → Menu → Chambers / Settings / Credits
- Procedural ambient + SFX (no large audio pack yet)
